# BatBlack

Jogo de corrida infinita em pixel art 8-bit do morcego BatBlack.

🔗 Acesse o projeto: https://batblack.netlify.app/

---

## 📋 Sobre o projeto

O **BatBlack** é um jogo de corrida infinita inspirado no clássico Chrome Dino, desenvolvido com visual pixel art 8-bit.

O jogador controla um morcego que precisa desviar de obstáculos em três alturas dinâmicas (chão, meio e alto). O jogo conta com sistema de pontuação, recorde local, modo noturno, sons e suporte completo a Progressive Web App (PWA).

A proposta é oferecer uma experiência leve, divertida e 100% no navegador, com foco em fluidez, visual retrô e jogabilidade simples tanto no desktop quanto no celular.

---

## ✨ Funcionalidades

* Corrida infinita com dificuldade progressiva
* Três faixas de altura dinâmicas (chão, meio e alto)
* Obstáculos variados (gatos, pedras e galhos)
* Sistema de pontuação e recorde salvo no navegador
* Modo noturno automático
* Controles por teclado e toque (mobile)
* Sons e mute
* Progressive Web App (instalável no celular e computador)
* Interface responsiva e otimizada para tela cheia
* Funciona 100% offline após a instalação

---

## 🛠️ Tecnologias

* React 19
* TypeScript
* Vite
* Tailwind CSS 4
* Canvas 2D
* vite-plugin-pwa
* Progressive Web App (PWA)

---

## 🎮 Controles

* **Desktop:** Setas ↑ / ↓ ou teclas W / S para mudar de faixa
* **Mobile:** Toque na parte superior ou inferior da tela
* Botões de mute, tela cheia e reiniciar disponíveis na interface

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/batblack.git
```

### 2. Entre na pasta

```bash
cd batblack
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

O projeto utiliza a porta `3000` em desenvolvimento.

Acesse:

```text
http://localhost:3000
```

---

## 📦 Build para produção

```bash
npm run build
```

A pasta gerada será a `dist`, pronta para deploy no Netlify.
